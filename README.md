- 🔬 **Nghiên cứu cốt lõi:** 
  - Machine Learning Engineering
  - Computer Vision: *Tiny Object Detection, Super-Resolution, OCR*
- 🏃‍♂️ **Kỷ luật:** Chạy bộ 5km mỗi ngày. Tiếng Nhật sơ cấp.
