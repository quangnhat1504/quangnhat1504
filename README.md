## Selected Projects

### [TrafficFlow — Vehicle Detection and Counting](https://github.com/quangnhat1504/Traffic-Flow)
*AI Pipeline Engineer · Team project*

- Developed the computer vision pipeline for identifying, tracking, and counting vehicles by lane and travel direction in uploaded videos and live streams.
- Worked on region-of-interest geometry, YOLO detection, ByteTrack tracking, lane assignment, and line-crossing events. These details help prevent double counting and keep results consistent with the road layout.
- Documented evaluation results and limitations. On the held-out UA-DETRAC benchmark described in the repository, the system reported **0.942 event-level F1** for vehicle counting.

### [Tiny Object Detection — Ongoing Research](https://github.com/quangnhat1504/Tiny_Object_Detection)
*Computer vision research*

- Investigating how bounding-box comparison and localization methods behave when objects occupy very few pixels in an image.
- Working with experimental notebooks and controlled comparisons, with an emphasis on reproducibility, evaluation discipline, and separating model development from final testing.
- **Status:** Research in progress; experimental findings are not presented here as published or independently validated results.
